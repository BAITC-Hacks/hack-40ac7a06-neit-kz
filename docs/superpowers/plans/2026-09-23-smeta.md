# Смета на мероприятие — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** По многопозиционному запросу («фотограф + ведущий + лайв-бэнд») показывать три набора — Эконом, Ваш выбор, Люкс — каждый одной строкой с суммой и отношением к бюджету.

**Architecture:** Новый модуль `lib/combo.ts` — чистая функция над уже готовыми `MatchResponse` каждой позиции. Ни сети, ни модели, ни системных часов. Позиции независимы, поэтому перебора нет: эконом — минимум цены в каждой позиции, люкс — максимум, тай-брейк по `id`. Ядро (`filters`, `scoring`, `match`, `explain`) не трогается, `samples/golden/S1..S12` остаются байт в байт.

**Tech Stack:** TypeScript strict, Next.js 16 App Router, React 19, Tailwind 4, тесты на `node:test` через `tsx`.

**Спека:** [`docs/superpowers/specs/2026-09-23-smeta-design.md`](../specs/2026-09-23-smeta-design.md)

```ts
import type { Card, Outcome } from './types';

/**
 * Смета на мероприятие: наборы подрядчиков сразу по нескольким позициям.
 *
 * Чистая функция над готовыми ответами match(): ни сети, ни модели, ни системных часов —
 * тот же контракт, что у applyFilters. Позиции независимы, поэтому перебора нет:
 * эконом это минимум цены в каждой позиции, люкс — максимум. O(n), а не O(pool^n).
 *
 * Позиционный потолок по бюджету остаётся в фильтрах, поэтому набор из прошедших карточек
 * арифметически не может вылезти за общий бюджет. Единственное исключение — проезд:
 * он в позиционный фильтр не входит (см. Task 3).
 */

export type ComboKind = 'economy' | 'custom' | 'lux';

export type ComboPick = {
  category: string;
  cardId: string;
  name: string;
  priceFromKzt: number;
  /** проезд из другого города; 0 для местных */
  travelKzt: number;
  /** карточка взята из блока послаблений — в наборе есть оговорка */
  soft?: string;
};

export type Combo = {
  kind: ComboKind;
  label: string;
  picks: ComboPick[];
  totalKzt: number;
  travelKzt: number;
  budgetKzt?: number;
  /** >0 — остаток, <0 — превышение; undefined, если бюджет не назван */
  deltaKzt?: number;
  fitsBudget: boolean;
  /** категории, по которым в набор некого поставить */
  missing: string[];
  /** набор собран из тех, кто не прошёл фильтры: справочный, выбрать нельзя */
  hypothetical: boolean;
  line: string;
  note: string;
};

export type ComboPosition = {
  category: string;
  cards: Card[];
  softCards: Card[];
  nearestCards: Card[];
  outcome: Outcome;
};

const LABEL: Record<ComboKind, string> = {
  economy: 'Эконом',
  custom: 'Ваш выбор',
  lux: 'Люкс',
};

const money = (n: number) => `${n.toLocaleString('ru-RU')} ₸`;
const num = (n: number) => n.toLocaleString('ru-RU');

/** Дешевле — меньше цена; при равной цене меньший id. Тот же тай-брейк, что в byScoreThenId. */
function cheapest(cards: Card[]): Card | undefined {
  return [...cards].sort((a, b) => a.priceFromKzt - b.priceFromKzt || a.id.localeCompare(b.id))[0];
}

function dearest(cards: Card[]): Card | undefined {
  return [...cards].sort((a, b) => b.priceFromKzt - a.priceFromKzt || a.id.localeCompare(b.id))[0];
}

function toPick(category: string, card: Card): ComboPick {
  return {
    category,
    cardId: card.id,
    name: card.name,
    priceFromKzt: card.priceFromKzt,
    travelKzt: card.relaxation?.travel?.totalKzt ?? 0,
  };
}

function segments(picks: ComboPick[]): string[] {
  return picks.map((p) => `${p.name} ${num(p.priceFromKzt)}`);
}

function assemble(
  kind: ComboKind,
  picks: ComboPick[],
  missing: string[],
  budgetKzt?: number,
): Combo {
  const travelKzt = picks.reduce((s, p) => s + p.travelKzt, 0);
  const totalKzt = picks.reduce((s, p) => s + p.priceFromKzt, 0) + travelKzt;
  const deltaKzt = budgetKzt === undefined ? undefined : budgetKzt - totalKzt;
  const tail =
    deltaKzt === undefined
      ? ''
      : deltaKzt >= 0
        ? ` · остаток ${money(deltaKzt)}`
        : ` · на ${money(-deltaKzt)} выше бюджета`;

  return {
    kind,
    label: LABEL[kind],
    picks,
    totalKzt,
    travelKzt,
    budgetKzt,
    deltaKzt,
    fitsBudget: deltaKzt === undefined || deltaKzt >= 0,
    missing,
    hypothetical: false,
    line: `${segments(picks).join(' + ')} = ${money(totalKzt)}${tail}`,
    note: '',
  };
}

/**
 * Совпадающие наборы не прячем и не схлопываем: спрятать — значит показать два варианта
 * вместо трёх и заставить человека гадать, куда делся третий.
 */
function withNotes(combos: Combo[]): Combo[] {
  const ids = (c: Combo) => c.picks.map((p) => p.cardId).join('|');
  const [economy, custom, lux] = combos;
  economy.note = 'самый дешёвый набор из тех, кто прошёл все фильтры';
  lux.note = 'самый дорогой набор из прошедших';
  custom.note =
    ids(custom) === ids(economy)
      ? 'совпадает с экономом: самый подходящий оказался и самым дешёвым'
      : ids(custom) === ids(lux)
        ? 'совпадает с люксом: самый подходящий оказался и самым дорогим'
        : 'по одному лучшему в каждой позиции';
  return combos;
}

export function buildCombos(
  positions: ComboPosition[],
  budgetKzt?: number,
  selection?: Record<string, string>,
): Combo[] {
  const missing = positions.filter((p) => p.cards.length === 0).map((p) => p.category);

  const byRule = (choose: (p: ComboPosition) => Card | undefined): ComboPick[] =>
    positions
      .map((p) => {
        const card = choose(p);
        return card ? toPick(p.category, card) : undefined;
      })
      .filter((x): x is ComboPick => x !== undefined);

  const combos = [
    assemble('economy', byRule((p) => cheapest(p.cards)), missing, budgetKzt),
    assemble(
      'custom',
      byRule((p) => {
        const chosen = selection?.[p.category];
        return (chosen ? p.cards.find((c) => c.id === chosen) : undefined) ?? p.cards[0];
      }),
      missing,
      budgetKzt,
    ),
    assemble('lux', byRule((p) => dearest(p.cards)), missing, budgetKzt),
  ];

  return withNotes(combos);
}
```

/** Русские склонения: в 1 раз, в 2 раза, в 5 раз. Дробная кратность всегда «раза». */
function timesWord(n: number): string {
  if (!Number.isInteger(n)) return 'раза';
  const m10 = n % 10;
  const m100 = n % 100;
  if (m10 === 1 && m100 !== 11) return 'раз';
  if (m10 >= 2 && m10 <= 4 && (m100 < 12 || m100 > 14)) return 'раза';
  return 'раз';
}

/**
 * Набор из тех, кто не прошёл фильтры. Строится, только когда не прошёл никто нигде:
 * иначе получился бы выбор между реальным и невозможным, а это обман.
 * Выбрать его нельзя — он отвечает на вопрос «сколько это вообще стоит».
 */
function hypothetical(positions: ComboPosition[], budgetKzt?: number): Combo {
  const picks = positions
    .map((p) => {
      const card = cheapest(p.nearestCards);
      return card ? toPick(p.category, card) : undefined;
    })
    .filter((x): x is ComboPick => x !== undefined);

  const totalKzt = picks.reduce((s, p) => s + p.priceFromKzt + p.travelKzt, 0);
  const ratio = budgetKzt ? totalKzt / budgetKzt : 1;
  // Кратность ниже 1,2 звучит отпиской: «в 1,03 раза выше» — лучше назвать деньги.
  const over =
    budgetKzt === undefined
      ? ''
      : ratio > 1.2
        ? ` · это в ${ratio.toLocaleString('ru-RU', { maximumFractionDigits: 2 })} ${timesWord(ratio)} выше вашего бюджета`
        : ` · это на ${money(totalKzt - budgetKzt)} выше вашего бюджета`;

  return {
    kind: 'economy',
    label: 'Минимальный набор',
    picks,
    totalKzt,
    travelKzt: picks.reduce((s, p) => s + p.travelKzt, 0),
    budgetKzt,
    deltaKzt: budgetKzt === undefined ? undefined : budgetKzt - totalKzt,
    fitsBudget: budgetKzt === undefined,
    missing: positions.map((p) => p.category),
    hypothetical: true,
    line: `Дешевле этого набора в каталоге нет: ${segments(picks).join(' + ')} = ${money(totalKzt)}${over}`,

## Смета на мероприятие

Клиент редко ищет одного подрядчика. «Нужны фотограф, ведущий и лайв-бэнд» — это три подбора,
и главный вопрос у него не «кто лучше в каждой позиции», а **«сколько это будет стоить целиком
и влезу ли я в бюджет»**.

Над позициями считается смета: три набора, каждый одной строкой.

| Набор | Как собран |
|---|---|
| **Эконом** | самый дешёвый в каждой позиции из тех, кто прошёл все семь фильтров |
| **Ваш выбор** | по одному лучшему по совпадению; меняется кликом по карточке |
| **Люкс** | самый дорогой из прошедших |

Считает это чистая функция `lib/combo.ts` — ни сети, ни модели, ни системных часов.
Позиции независимы, поэтому перебора нет: O(n) вместо O(pool^n). Тай-брейк по `id`,
как и везде в проекте, — при равной цене набор не «пляшет» между прогонами.

**Три вещи, которые смета делает честно:**

1. **Проезд входит в сумму.** Подрядчик из другого города приезжает не бесплатно;
   `estimateTravelCost` в позиционный фильтр не входит, поэтому набор с ним — единственный,
   который может вылезти за бюджет. Строка говорит об этом числом.
2. **Один профиль на двух позициях оплачивается один раз.** <N> профилей из <M> числятся больше
   чем в одной категории, и пересечения структурные: «Национальный ансамбль» ⊂ «Танцевальный
   коллектив» ⊂ «Шоу-программа». Без дедупликации смета удвоила бы цену одного человека.
3. **Пустой экран получает число.** Когда не проходит никто ни в одной позиции — а при заниженном
   бюджете на три позиции это обычное дело, доли по медианам оказываются ниже самой дешёвой цены —
   смета собирается из блока «ближайшее» и отвечает: «дешевле этого набора в каталоге нет, <сумма>,
   это в <кратность> раза выше вашего бюджета». Выбрать такой набор нельзя, он справочный.

Проверяется эталонами `samples/golden/C1.json`, `C2.json`, `C3.json` (`npm run verify`) и тестами
`tests/combo.test.ts`.

## Чего в этом плане нет — и почему

| Не делаем | Почему |
|---|---|
| Снять позиционный потолок по бюджету | Правильнее по существу, но меняет воронку и все эталоны. Решение принято при написании спеки: до защиты ядро не трогаем |
| Динамика по бюджету (рюкзак) | При сохранённом потолке ограничение не связывает — любой набор из прошедших уже в бюджете. Код без применения |
| Эконом из всего пула, а не из показанных карточек | Смета обязана ссылаться на то, что человек видит на экране |
| Четвёртый набор «оптимум по score в бюджете» | Три строки читаются за секунду, четыре — уже таблица |
| Сохранение и отправка сметы | Ни базы, ни почты в проекте нет |
